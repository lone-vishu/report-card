# Student Report Card System (Python Project)

A beginner-friendly Python project that generates and manages a student's report card based on subject marks.

This project demonstrates how basic programming concepts can be used to calculate results, averages, and performance evaluation.

---

## 📌 Project Overview

The program takes student details and marks as input, then:

### Features:
- Stores student information
- Calculates total marks
- Calculates average marks
- Determines pass/fail status
- Displays formatted report card

The project is designed to strengthen problem-solving and logic-building skills using Python.

---

## 🛠 Concepts Used

- Variables & Data Types
- User Input Handling
- Arithmetic Operations
- Conditional Statements
- Functions
- Lists
- Formatted Output

---

## ▶️ How to Run

1. Install Python
2. Download the project file
3. Run the program using terminal:

```bash
python report_card.py
```
